# Umang Pankaj Portfolio

A self-contained, responsive static portfolio for Vercel, built with HTML/CSS/JavaScript.

## Preview locally
Open `index.html` in a modern browser. For the best experience, serve this directory with a local web server (for example `python -m http.server 8000`) and visit `http://localhost:8000`.

## Deploy to Vercel
1. Upload this directory to a new GitHub repository, or keep the directory locally.
2. In Vercel, import the GitHub repository, or deploy the folder with the Vercel CLI (`vercel` for a preview; `vercel --prod` when ready for production).
3. No build command or server-side environment variables are needed; this is a static site. Keep the root `index.html` and `assets/portrait.jpg` together.

## Interactions
- Responsive sticky navigation with a mobile menu.
- Project category filters and accessible case-study modal dialogs.
- Reduced-motion support and keyboard operation.
- Gmail compose, `mailto:`, click-to-call, LinkedIn, and copy-email action.
- Completed certificates are separated from in-progress learning. No unprovided public certificate links or project demo URLs are fabricated.
